# astrbot-plugin-meme · 每日梗图

群里发一句 `/meme`，随机来一张梗图；群友发的图 `@bot /meme 投稿` 就进图库。
所有进来的图都过一遍**多模态审核**（色情 / 血腥 / 现实政治 / 广告水印 / 是不是梗图），
英文梗图自动**中文化**，对味的图越攒越多，抽到的也就越来越对味。

- **三源合一**：群友投稿 / 第三方接口 / AI 现画（预留），互斥按权重抽。**不带内置素材**，装好之后库里是空的。
- **自动搬石**：卡片上点「自动订阅」，选低/中/高（每小时 10/25/50% 概率自动发一张），管理员可关。
- **一个库，所有群共用**：不再有「单群图库」，投一次到处都能刷到。
- **只有一份审核和投递实现**：任何来源的图都走同一条管线，不会有一条路绕开审核。
- **不发脏话过滤表**：只按「类别开关 + 色情等级阈值」判断，梗图的谐音黑话不会被误杀。
- **被动优先**：`/meme` 是一次被动回复，不需要任何主动消息权限就能用。

---

## 一、装完之后干什么（三步）

1. **在「提供商」里确认有两个可用模型**
   - 一个**能看图**的多模态模型（审核用）——比如 `gemini-3.1-flash-lite` / `gpt-6-astra` / `grok-4.7`；
   - 一个**能画图**的 OpenAI 兼容线路（只有选 `redraw` 才需要）。
2. **插件配置里点一下选择**
   - 「审核用多模态 Provider」→ 从提供商里选（`_special: select_provider`，就是个下拉选择器）；
   - 「英文梗图怎么变中文」→ 先用默认的 `append`（只翻字幕，不动画面）。
3. **群里试**：先 `/meme 投稿` 投一张进去，再 `/meme` 看能不能发出来；`/meme 测试`（管理员，引用一张图看审核 JSON）。

> 说白了：**库里一开始是空的**，得先有人投稿（或在面板上拖图进去）。投稿会被拒收的唯一原因是没配审核模型——因为「没人看过的图不进库」是默认策略。

## 二、命令

| 命令 | 谁能用 | 干什么 |
| --- | --- | --- |
| `/meme`（别名 `梗图`、`来张梗图`） | 所有人 | 随机发一张 |
| 发图 + `/meme 收` | 所有人 | 投稿（先审后收）；直接发图不带子命令也算投稿 |
| `/meme 库` | 所有人 | 看这个群有多少张能发、来源分布、被拒收了几张 |
| `/meme 每日` | 所有人 | 看每日推送状态 |
| `/meme 每日 9:00,21:00` / `/meme 每日 关` | 管理员 | 开/关定时推送 |
| `/meme 删 <编号>` | 管理员 | 下架一张 |
| `/meme 审核 <编号>` | 管理员 | 重新审一次；不通过会自动下架 |
| `/meme 拉` | 管理员 | 立刻从第三方接口拉一张入库 |
| `/meme 测试` | 管理员 | 跑一遍审核管线，把模型回的 JSON 打给你看 |
| `/meme 帮助` | 所有人 | 上面这些 |

管理员 = AstrBot 全局 `admins_id`，或配置里的「额外的管理员 ID」。

## 三、配置项（都能在面板里改，每项都有「说白了」的说明）

最关键的五项：

| 配置 | 默认 | 说白了 |
| --- | --- | --- |
| `moderation_provider_id` | 空 | 审核用的多模态模型。**不选 = 投稿一律拒收** |
| `nsfw_max_level` | `1` | 色情等级上限（0 安全 … 4 露骨）。填 1 = 轻微暗示可以，擦边不收 |
| `reject_flags` | `gore, politics, ads_or_watermark, minor, hate` | 直接拒收的类别 |
| `caption_zh_mode` | `append` | `off` 不管 / `append` 只翻字幕 / `redraw` 真重画中文版 |
| `weight_submitted` | `3` | 抽图时投稿图的权重（另外两个来源：`weight_api`、`weight_generated`） |
| `auto_push_low_pct` / `mid` / `high` | `10 / 25 / 50` | 选了「低/中/高」的群，每小时自动发一张的概率（%） |
| `auto_push_max_per_day` | `8` | 每群每天最多自动发几条，0 = 不限 |
| `auto_push_quiet` | `23:00-08:00` | 这段时间不自动发（可跨零点，留空 = 全天） |
| `auto_push_bootstrap` | `true` | 启动时把还没订阅的群静默开到低档去试（发不出去会自动退订） |
| `auto_push_bootstrap_days` | `30` | 批量铺开只挑最近多少天有动静的群，0 = 不限 |
| `redraw_size` | `auto` | 重画尺寸。`auto` = 按原图横竖自动挑画布，画完裁回原比例 |

其余见 `_conf_schema.json`，每一项都有中文标题和大白话解释。

## 四、管线长什么样

```
                     ┌──────────── 三源 ────────────┐
   群友投稿(submitted) │ 第三方接口(api)              │  AI 现画(generated, 预留)
                     └──────────────┬───────────────┘
                                    ▼
                       字节校验（是不是图 / 多大）
                                    ▼
                     sha256 查重 → 审核缓存命中？（只花一次钱）
                                    ▼
                   多模态审核 → {"is_meme","nsfw_level","flags","caption_text","language"}
                                    ▼
                 类别开关 + 色情阈值 + 是否梗图 → 拒收就记 sha256，永不重审
                                    ▼
                 caption_zh_mode：append 翻字幕 / redraw 重画（重画完再审一次）
                                    ▼
                            落盘 + SQLite 入库
                                    ▼
                   投递：Hub 富媒体 → AstrBot 原生图片 → 纯文字
```

## 五、上线时会踩到的三件事（都已处理）

1. **Provider 是插件之后才加载的**。AstrBot 的启动顺序是
   `plugin_manager.reload()` → `provider_manager.initialize()`，所以在插件
   `initialize()` 里 `get_provider_by_id()` 一定拿到 `None`。管线因此改成
   **首次使用时才解析**（`0.1.1`），失败的解析不缓存，下次自己接上。

2. **容器里要走代理**。AstrBot 配了 `http_proxy`（如 `172.18.0.1:7890`），
   但容器里通常**没有代理环境变量**，httpx 默认直连 → `Network is unreachable`。
   插件自己发的请求（拉图/下载投稿图/调画图接口）从配置 `http_proxy` 取代理，留空跟随全局。

3. **`platformgate` 会拦新插件**。它的 `default_allow_all` 是 `false`，
   没写进 `qq_official` 名单的插件在群里会被回「该功能在此平台不可用」。
   装完插件记得在 `data/plugin_data/astrbot_plugin_platformgate/rules.json`
   里给 `astrbot_plugin_meme` 补一条 `true`（插件被禁用时无所谓）。

## 六、为什么这么设计

- **审核只有一处实现**：图中任何一个来源如果有自己的审核逻辑，早晚会有一个入口漏掉。
- **不是关键词黑名单**：梗图的文字是谐音、错字、黑话，关键词表既误杀好图又漏掉真问题；判断画面的是模型。
- **`fail_closed` 默认开**：审核超时/报错/回话解析不出来时**拒收**，而不是当作「干净」放行——「审核挂了」和「审核通过」是两件事。
- **`redraw` 一定要重审**：画图模型偶尔会把正常图改成擦边图，所以重画版必须再过一次；不过就退回原图 + 字幕模式。
- **主动推送有前提**：QQ 官方群主动消息要**群主在群设置里打开「机器人主动在群聊内发言」**，否则接口回 `40034105 主动消息失败, 无权限`；插件收到这个错误会**静默停推 24 小时**并只记日志，不在群里刷报错。

## 七、开发

```bash
python -m pytest -q          # 320+ 项，不需要装 AstrBot
```

`meme/` 里一行 `astrbot` 都不 import：审核判定、入库、随机挑选、投递降级全是纯逻辑，
`main.py` 才是唯一碰框架的地方（把 provider 包成 adapter、把 event 包成 sender）。

## 八、约定与边界

- 图库**只有一份**，所有群共用；「单群图库」这套（`scope=group`）已经删掉了。
- 插件**不自带任何图片**：装好之后库里是空的，要靠投稿/接口/面板导入。
- 素材只收 **jpg / png / gif / webp**，单张默认 ≤ 8MB（QQ 自己是 10MB 上限，留了余量）。
